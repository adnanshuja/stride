# UI System

## Colors
| Token | Hex | Usage |
|-------|-----|-------|
| midnight | `#0C0E1D` | page background |
| surface | `#211F36` | card/input bg |
| mint | `#51FAAA` | primary actions, FREE, success |
| mint-dark | `#29D97A` | button hover |
| magenta | `#FF81FF` | RESTRICTED, secondary |
| text | `#f1f5f9` | primary |
| muted | `#94a3b8` | secondary |
| dim | `#475569` | subtle |

## Glass
```
glass        → bg: rgba(33,31,54,0.65)  blur(24px)  border: 1px rgba(255,255,255,0.06)
glass-strong → bg: rgba(33,31,54,0.88)  blur(32px)  border: 1px rgba(255,255,255,0.08)
```

## Typography
| Usage | Font | Weight | Size |
|-------|------|--------|------|
| Body | Inter | 400-500 | 12-14px |
| Display | Sora | 700-800 | 24-48px |
| Mono | JetBrains Mono | 400-500 | 11-13px |

Labels: uppercase + tracking-wider/widest

## Decorative
- `.noise-overlay` — fixed SVG fractal noise 2% opacity z-9999 via `::after`
- `.bg-grid` — 1px white 2% grid lines, 64px spacing
- Ambient orbs — radial gradients 5-12% opacity blur(100-120px) at corners

## Animations
| Name | Duration | Effect |
|------|----------|--------|
| fade-up | 0.5s | translateY(16px)→0 + opacity |
| slide-in-up | 0.6s | translateY(24px)→0 + opacity |
| fade-in | 0.4s | opacity 0→1 |
| pulse-mint | 3s | box-shadow mint glow |
| pulse-magenta | 3s | box-shadow magenta glow |
| float | 6s | translateY oscillation |

Stagger: `.animate-stagger-1` (0.05s) → `.animate-stagger-8` (0.4s) — needs `animate-fade-up` on element

## Button states
default: rounded-full mint bg dark text shadow-lg mint/20
hover: darker mint, stronger shadow
active: scale(0.97)
disabled: opacity-40 pointer-events-none
