# UI System

Full design system: `DESIGN.md` (root). This file is a quick-reference for commonly-used tokens.

## Colors
| Token | Hex | Usage |
|-------|-----|-------|
| midnight | `#0C0E1D` | page background |
| surface | `#1A1C2E` | card/input bg |
| raised | `#211F36` | modals, overlays, glass bg |
| mint | `#51FAAA` | single accent — ALL interactive elements |
| mint-dark | `#29D97A` | button hover |
| magenta | `#FF81FF` | RESTRICTED state only |
| text | `#f1f5f9` | primary |
| muted | `#94a3b8` | secondary |
| dim | `#475569` | subtle |

## Glass
```
glass        → bg: rgba(33,31,54,0.65)  blur(24px)  border: 1px rgba(255,255,255,0.06)
glass-strong → bg: rgba(33,31,54,0.88)  blur(32px)  border: 1px rgba(255,255,255,0.08)
```

## Typography
| Usage | Font | Weight | Size |
|-------|------|--------|------|
| Body | Inter | 400-500 | 12-14px |
| Display | Sora | 700-800 | 24-48px |
| Mono | JetBrains Mono | 400-500 | 11-13px |

Labels: uppercase + tracking-wider/widest, 9-11px JetBrains Mono

## Decorative
- `.noise-overlay` — fixed SVG fractal noise 1.5% opacity z-9999 via `::after`
- `.bg-grid` — 1px white 2% grid lines, 64px spacing
- No ambient orbs, no decorative blobs, no gradients on backgrounds

## Animations
Minimal-functional — micro-interactions on hover/click only. No entrance animations. No page transitions.

| Name | Duration | Effect |
|------|----------|--------|
| pulse-mint | 3s | box-shadow mint glow |
| pulse-magenta | 3s | box-shadow magenta glow |

Stagger: `.animate-stagger-1` (0.05s) → `.animate-stagger-8` (0.4s)

## Button states
default: rounded-full mint bg dark text shadow-lg mint/20
hover: darker mint, stronger shadow
active: scale(0.97), duration-150
disabled: opacity-40 pointer-events-none
